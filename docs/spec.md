# 模板配置

每个模板一份 JSON 配置,各步脚本只读它。`scripts/batch.py` 按品类预设给每张源图生成一份,存在 `batches/<批次>/specs/<id>.json`。配置里的路径都相对仓库根目录。

预设(`presets/<预设>.json`)用同样的 `category`、`occluders`、`products` 字段,另有文件夹别名和裁切规则,见 [batch.md](batch.md#预设)。

## 顶层字段

| 字段 | 内容 |
| --- | --- |
| `id` | 模板 id,也是 `work/`、`output/`、`preview/` 下的目录名 |
| `category`、`tags` | 品类(小品类 slug,可为 `null`)、标签列表,写进 `template.json` |
| `photo` | 源图。带透明度的叠在白色上;透明度不到 1 的像素视为不是原始照片,落在商品区外时,底图里换成周围的背景色 |
| `crop` | 可选,`[x0, y0, x1, y1]`(像素),先裁出这一块再用;各脚本和封面都用裁好的图 |
| `size` | 可选,`[宽, 高]`,裁好后再缩放到这个尺寸。`batch.py` 在裁好的图不是 2048 × 2560 / 2560 × 2048 时写上(vorla 后端按这个尺寸收模板) |
| `fetch` | 可选,要下载的素材 `{路径: {url, sha256}}`,`scripts/fetch_sources.py` 按它下载 |
| `occluders` | 遮挡物的提示列表,格式见下 |
| `products` | 商品列表,由上层到下层,见下 |
| `preview` | 预览的裁切范围 `crop`(占宽高的比例)和边缘放大的取样位置 `spots`(`[名称, x, y]`,模板像素) |

## 提示的格式

`occluders`、`products[].parts` 和商品本身的分割提示都用这种格式:

- `{text: 名词短语}`:SAM 3 按文字分,图里所有符合的实例合在一起,如 `"bag strap"`;
- `{box: [x0, y0, x1, y1], points: [[x, y, 1 正 / 0 负], ...]}`:SAM 2.1 按框和点分,文字分不准时手点兜底。

遮挡物的提示另可写:

- `matteBand`:和商品交界的待求带半宽 / 宽度,不写为 `0.004`;头发这类边上有细丝的放宽,如 `0.015`;
- `note`:只作说明。

## 商品 `products[]`

| 字段 | 内容 |
| --- | --- |
| `id` | 文件名用 |
| `key`、`name` | 写进 `template.json` |
| `text` 或 `box` + `points` | 分割提示 |
| `alternatives` | 可选,备选说法列表。`text` 一个实例都分不出、或 Gemini 说分出的都不是商品时按顺序换着试。各说法都在阈值 0.5 试过才放低阈值,所以备选说法在 0.5 分得出时优先于 `text` 在低阈值分出 |
| `instance` | 可选,文字提示挑剩的实例里只取从左往右第几个(从 0 数)。一张图里两件同类商品时各写一件 |
| `parts` | 可选,不可印部件的提示列表(如袖子、领口) |
| `print` | 可印区域规则,见下 |
| `logo` | 可选,默认 Logo 框的放法,见下 |
| `solid` | 可选,`true` 时商品没有镂空:横穿商品的细缝(宽度的 0.4% 以内)接上,蒙版里的洞不论大小全补上。不写时只补不到整件 0.2% 的小洞,更大的当作提手、包带围出来的背景 |
| `hull` | 可选,`true` 时看得见的轮廓是凸的,蒙版换成最大一块的凸包 |
| `recolorable` | 可选,默认 `true` |
| `binaryEdge` | 可选,源图里这件商品的轮廓是台阶,抠图救不回来:按二值来源处理,平滑轮廓后重出软边 |
| `reference` | 可选,对比用的参考蒙版 `{product, print}`,每项 `{file, transparent}`;`transparent` 取图里半透明的部分,否则取白色 × 透明度。`pipeline.py` 最后打印重合度,不算校验 |

## 可印区域 `products[].print`

可印区 = 商品区减去 `parts`,再按下面的规则取:

| 字段 | 内容 |
| --- | --- |
| `inset` | `{top, bottom, left, right}`,按宽度的比例从商品和背景的交界往里收,只写需要的那几侧。部件、遮挡物和上层商品的边上不收 |
| `rows` | `[从, 到]`,只留这段高度(占商品高度的比例) |
| `largest` | `true` 时只留最大的一块(部件把可印区切开时,如围裙的腰带) |
| `face` | `true` 时只留正对的那一面:法线和可印区法线中位数的夹角在 35° 以内、连成一片的最大一块。用在盒子、书、本子、纸袋这类硬的多面商品,侧面、书脊不印;剩下的不到原来 30% 时不收窄 |
| `bridge` | `true` 时,校验「可印区最大一块」把带可印区的几块商品合起来的凸包当遮挡物。用在敞开的拉链外套:可印区本来就是左右两片前襟,中间隔着拉链和内搭 |

## 默认 Logo 框 `products[].logo`

| 字段 | 内容 |
| --- | --- |
| (不写) | 正方形,放在可印区正中 |
| `top` | 框中心在可印区从上往下的位置,上衣写 `0.32`(胸口) |
| `side: "left"` | 和 `top` 一起写,放在左胸 |
| `closure` | 让 Gemini 判断照片是不是这件的正面、前襟有没有拉链或扣子,是就合上里面的设置 |
| `fill: true` | 铺满可印区(平面印刷品) |
| `freeform: true` | 可印区是异形时框不转(贴纸、袜子、钥匙扣) |
| `width` | 框的大小,默认 `0.4` |
| `split` | 单只的说法,或几个说法的列表(按顺序试,分出两只就停),框只放在 SAM 3 分出的最大那只上(袜子、裤子、短裤) |

预设里的惯例:

- 上衣写 `top`;卫衣、夹克、球衣、polo 衫、运动套装的上衣另写 `closure: {side: "left"}`;
- 平面印刷品写 `fill`,贴纸另写 `freeform`;
- 袜子写 `split: "sock"`、`top: 0.3`、`freeform: true`,裤子写 `split: "pant leg"`、`top: 0.25`;短裤写 `split: ["leg of the shorts", "shorts leg"]`,框放在那只裤腿正中(SAM 3 按 pant leg 分不出短裤的裤腿,两个说法各有分不出的照片)。

各种放法具体怎么算,见 [how-it-works.md](how-it-works.md#默认-logo-框)。
